# Заметки

Простое учебное веб-приложение.

## Что есть

- добавление заметок в список;
- сохранение данных в `localStorage`;
- работа офлайн через `Service Worker`;
- файл `manifest.json` для PWA;
- загрузка контента из папки `content`;
- уведомления через `Socket.IO` и push;
- добавление заметки с напоминанием;
- откладывание напоминания на 5 минут.

## Как запустить

```bash
npm.cmd install
node server.js
```

Потом открыть в браузере:

```bash
http://localhost:3001
```

## HTTPS

Если нужен HTTPS, можно создать сертификаты через `mkcert` и положить их в корень проекта:

```bash
mkcert -install
mkcert localhost 127.0.0.1 ::1
```

Нужны файлы:

- `localhost.pem`
- `localhost-key.pem`

После этого снова запустить:

```bash
node server.js
```

И открыть:

```bash
https://localhost:3001
```

## Важно

- файл `vapid-keys.json` создаётся автоматически при первом запуске;
- напоминания хранятся в памяти сервера;
- после перезапуска сервера напоминания сбрасываются.
